# AI Fitness Coach

An inclusive, multi-user AI fitness coaching application designed to generate dynamic, personalized workout plans for everyone from beginners to powerlifters. The application leverages Google's Gemini AI to analyze custom user inputs—including fitness level, target muscle groups, available equipment, and dietary preferences—to deliver highly tailored fitness routines.

## Architecture & Tech Stack

This project utilizes a decoupled frontend and backend architecture, deployed as separate microservices on Google Cloud Run.

* **Frontend:** Angular 21 (Standalone Components) served via Nginx.
* **Backend:** C# ASP.NET Core 10 Web API.
* **AI Integration:** Google Gemini AI API.
* **Infrastructure:** Docker, Google Cloud Buildpacks, Google Cloud Run (`us-east4`).
* **Routing:** Direct CORS communication between the Angular client and the C# API.

## Repository Structure

* `/FitnessApp.Api/` - Contains the C# ASP.NET Core backend solution.
* `/fitness-app-ui/` - Contains the Angular standalone frontend and Dockerfile.
* `main` branch - The active production architecture (C# API + Angular).
* `ai-studio-node` branch - A backup branch containing the initial Node.js layout generated by Google AI Studio.

## Prerequisites

To run this project locally, ensure you have the following installed:
* [.NET 10.0 SDK](https://dotnet.microsoft.com/)
* [Node.js](https://nodejs.org/) (v20+ recommended) and the [Angular CLI](https://angular.dev/)
* [Google Cloud CLI](https://cloud.google.com/sdk/docs/install) (for deployment)
* A valid Google Gemini API Key
